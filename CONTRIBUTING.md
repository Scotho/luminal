# Contributing

Luminal is published as-is and is not actively maintained. Issues and pull requests are welcome but may sit
unanswered. Forking is the realistic way to take it somewhere.

If you do send a pull request:

- `npm run typecheck`, `npm run lint` and `npm test` should pass.
- Use conventional commits (`feat(scope):`, `fix(scope):`, `chore:`).
- By contributing you agree your contribution is licensed under the MIT License, the same as the project.

## What a pull request must not contain

- **Audio, models or art you don't have the right to redistribute.** "I found it online" is not a license. Say
  where each new asset came from and what its license is, and add it to `NOTICE.md`.
- The files listed under "Assets deliberately left out" in `NOTICE.md`.
- Credentials, tokens, `.env` files or real account details.
